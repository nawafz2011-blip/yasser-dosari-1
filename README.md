# تلاوة الشيخ ياسر الدوسري — المصحف الكريم

تلاوة الشيخ ياسر الدوسري (حفص عن عاصم – مرتل) بجودة 128 kbps، سورة كاملة في كل ملف، تُستخدم في موقع وتطبيق **المصحف الكريم** للاستماع مع تظليل الآيات.

- الموقع: https://mushaff.com
- هذا الجزء: من سورة الفاتحة إلى سورة مريم (١–١٩). سورة البقرة مقسومة إلى ملفين (`002.mp3` و`002b.mp3` من الآية ١٤٢).
- مصدر التسجيل: mp3quran.net
